# CV Interactivo - Evaluación Final Módulo 2

Este proyecto consiste en un Currículum Vitae interactivo desarrollado como parte de la evaluación final del Módulo 2 en **Kibernum IT Academy**.

## Características principales:
- **Responsividad:** Construido con **Bootstrap 5** para adaptarse a dispositivos móviles, tablets y escritorio.
- **Interactividad:** Implementación de **jQuery** para efectos dinámicos.
- **Funcionalidades JS/jQuery:**
  - Alternador de Modo Claro/Oscuro.
  - Validación de formulario de contacto en tiempo real.
  - Efectos de animación al hacer scroll.
  - Cambio dinámico de estilos mediante botones.

## Tecnologías utilizadas:
- HTML5 (Etiquetas semánticas)
- CSS3
- Bootstrap 5
- JavaScript / jQuery
- Git / GitHub
